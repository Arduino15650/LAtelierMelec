Nouvel éditeur simple du manuel numérique — livraison du 30 septembre 2026.

Copiez uniquement les huit fichiers de ce dossier à la racine du dépôt GitHub,
en remplaçant les fichiers de même nom. Le nouveau manual-blocks.js doit aussi
être ajouté. Ne déposez pas ce fichier LISEZ_MOI.txt.

Fichiers : enseignant.html, eleve.html, manual-blocks.js, manual-teacher.js,
manual-student.js, manual.css, content-render.js, service-worker.js.

L’éditeur utilise des blocs ordonnés : texte, image et PDF. Vous pouvez ajouter
autant de blocs que nécessaire, monter ou descendre un bloc, le supprimer, puis
enregistrer. Une image n’est plus flottante dans un paragraphe : le texte qui
la suit reste éditable dans son propre bloc. La prévisualisation reprend cet
ordre. Les anciennes leçons sont converties à l’affichage sans modifier leurs
données tant que vous ne les enregistrez pas.

Les fichiers sont toujours stockés dans le stockage Supabase existant et le
contenu dans manual_sections.content_html. Aucune commande SQL n’est requise.
Un PDF est proposé à la consultation dans la leçon, sans bouton de téléchargement.
Comme pour toute page web, il est impossible d’empêcher absolument la copie
ou l’enregistrement par un élève ayant accès au document.

Contrôles réalisés localement avec une leçon simulée : reprise d’une image
ancienne, ajout d’image et de texte après PDF, déplacement, enregistrement,
prévisualisation et affichage élève. La connexion réelle à GitHub Pages et à
Supabase n’est pas validée par ce test local.

Aucun fichier n’a été publié automatiquement sur GitHub dans cette livraison.
